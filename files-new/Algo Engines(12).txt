6. ⚙️ CONTEXT STRIP GENERATION FLOW
________________


STEP 1 — Determine Eligible Context Types
IF time_of_day = LUNCH:
    include NEARBY_RESTAURANTS


IF user_energy = LOW:
    include QUICK_STOPS or CAFES


IF primary avg_duration high:
    include EXPERIENCES


IF density high:
    include NEARBY_ATTRACTIONS


________________


STEP 2 — Fetch Candidate Pool
SELECT *
FROM entity_nearby_index eni
JOIN entities e ON eni.target_entity_id = e.id
WHERE eni.source_entity_id = :primary_id
AND eni.distance_m < :distance_threshold
LIMIT 100;


________________


Distance Threshold Logic
WALK → 800m
BIKE → 2km
CAR → 5km


________________


STEP 3 — Filter Candidates
Apply hard filters:
1. Remove visited_entities
2. Remove recently shown entities
3. Remove closed places (if time-aware)
4. Remove irrelevant types


________________


STEP 4 — Score Each Candidate
________________


🧠 FINAL SCORING FORMULA
final_score =
    (0.30 * proximity_score)
  + (0.20 * rating_score)
  + (0.15 * popularity_score)
  + (0.15 * context_match_score)
  + (0.10 * diversity_score)
  + (0.10 * route_score)


________________


6.4.1 Proximity Score
proximity_score = 1 - (distance / max_distance)


________________


6.4.2 Rating Score
rating_score = (rating / 5) * log(review_count + 1)


________________


6.4.3 Popularity Score
popularity_score =
    global_popularity * 0.6 +
    recent_trend * 0.4


________________


6.4.4 Context Match Score
Based on tags:
IF time_of_day = LUNCH AND tag = LUNCH:
    +1


IF user_energy = LOW AND tag = QUICK:
    +1


Normalize to 0–1
________________


6.4.5 Diversity Score
penalty if:
    same cuisine repeated
    same category repeated


________________


6.4.6 Route Score
penalize:
    detours > 20% from direction of next anchor


________________
