MODULE — ELIGIBILITY ENGINE — FINAL LOCKED VERSION
Eligibility Engine Implementation Ready Spec
1) Purpose
The Eligibility Engine determines whether an entity is:
valid enough to be allowed anywhere in the feed
It is a hard gate, but should be used conservatively.
It should exclude only entities that are:
* invalid
* impossible
* misleading
* clearly unusable
* too weak / junk
________________


2) Golden Rule
❗ “Not ideal right now” ≠ “exclude”
Examples:
* museum at night → eligible
* park in poor weather → eligible
* rooftop brunch at 9 PM → eligible
* beach on cloudy day → eligible
These are not Eligibility problems.
They are handled later by:
* Context Engine
* Opportunity Engine
* Action Horizon Engine
* Slot Ranking Engine
________________

    'eligible' => true, // true | false

6) VALIDATOR 1 — IDENTITY VALIDATOR (FINAL)
Purpose
Determines whether the entity is a real, coherent, actionable thing.
________________


❌ FAIL if:
   * title is empty
   * OR lat is null
   * OR lng is null


Also fail if entity is structurally too incomplete:
   * content_completeness_score < 0.20


________________


Fail reason codes
   * JUNK_ENTITY
   * MALFORMED_ENTITY
   * INSUFFICIENT_IDENTITY


________________


Validator
private function identityValidator($item)
{
    $reasons = [];


    if (empty($item->title) || $item->lat === null || $item->lng === null) {
        $reasons[] = 'INSUFFICIENT_IDENTITY';
    }
    if (
        $item->content_completeness_score !== null &&
        $item->content_completeness_score < 0.20
    ) {
        $reasons[] = 'MALFORMED_ENTITY';
    }
    return [
        'passed' => empty($reasons),
        'reasons' => $reasons
    ];
}

7) VALIDATOR 2 — OPERATIONAL VALIDATOR (FINAL)
Purpose
Determines whether the entity is still operational / usable in the real world.
This should rely only on explicit source status.
________________


Step A — Derive operational state
private function deriveOperationalState($item)
{
    if ($item->is_permanently_closed === true || $item->closure_type === 'permanent') {
        return 'closed';
    }
    if (in_array($item->closure_type, ['cancelled', 'ended', 'season_ended'])) {
        return 'ended';
    }
    if (
        $item->is_temporarily_closed === true
        || in_array($item->closure_type, ['temporary', 'suspended'])
    ) {
        return 'temporarily_unavailable';
    }
    return 'open';
}
________________


❌ FAIL if:
   * operational_state == 'closed'
   * operational_state == 'ended'
   * operational_state == 'temporarily_unavailable'


Important rule
If operational fields are null:
   * operational_state = 'open'


Meaning: Missing operational data does not fail the entity.
________________


Fail reason codes
   * PERMANENTLY_CLOSED
   * NO_LONGER_OPERATING
   * CANCELLED
   * ENDED
   * TEMPORARILY_UNAVAILABLE
________________


Validator
private function operationalValidator($item)
{
    $reasons = [];
    $state = $this->deriveOperationalState($item);
    if ($state === 'closed') {
        $reasons[] = 'PERMANENTLY_CLOSED';
    } elseif ($state === 'ended') {
        $reasons[] = 'ENDED';
    } elseif ($state === 'temporarily_unavailable') {
        $reasons[] = 'TEMPORARILY_UNAVAILABLE';
    }
    return [
        'passed' => empty($reasons),
        'reasons' => $reasons
    ];
}

8) VALIDATOR 3 — TEMPORAL VALIDATOR (FINAL)
Purpose
Determines whether the entity is still valid within time.
This is important for:
   * events
   * temporary exhibitions
   * seasonal experiences
   * date-bound activities
________________


❌ FAIL if end date already passed
   * if (end_date != null && end_date < now())


________________


❌ FAIL if seasonal item is outside active season
if (
    is_seasonal == true &&
    season_start != null &&
    season_end != null &&
    today NOT BETWEEN season_start AND season_end
)
Important rule
Do not fail just because opening hours don’t fit the current time.
That belongs later, not here.
________________


Fail reason codes
   * EVENT_EXPIRED
   * SEASON_EXPIRED
   * DATE_WINDOW_CLOSED
________________


Validator
private function temporalValidator($item)
{
    $reasons = [];
    $today = now()->toDateString();
    if ($item->end_date && $item->end_date < now()) {
        $reasons[] = 'EVENT_EXPIRED';
    }
    if (
        $item->is_seasonal === true &&
        $item->season_start &&
        $item->season_end
    ) {
        if (!($today >= $item->season_start && $today <= $item->season_end)) {
            $reasons[] = 'SEASON_EXPIRED';
        }
    }
    return [
        'passed' => empty($reasons),
        'reasons' => $reasons
    ];
}

11) VALIDATOR 6 — QUALITY VALIDATOR (FINAL)
Purpose
Prevents junk / ultra-thin entities from entering the feed.
________________


❌ FAIL if:
   * content_completeness_score < 0.20
   * AND review_count < 5
This is a conservative quality floor.
It removes:
   * weak scraps
   * malformed thin listings
   * junk entities
But does not remove:
   * niche but valid entities
   * low-review real places with decent metadata
________________


Fail reason codes
   * LOW_QUALITY_JUNK
   * THIN_RECORD
   * NON_ACTIONABLE_PLACE
________________


Validator
private function qualityValidator($item)
{
    $reasons = [];
    if (
        $item->content_completeness_score !== null &&
        $item->content_completeness_score < 0.20 &&
        ($item->review_count ?? 0) < 5
    ) {
        $reasons[] = 'LOW_QUALITY_JUNK';
    }
    return [
        'passed' => empty($reasons),
        'reasons' => $reasons
    ];
}

12) FINAL MERGE LOGIC
Eligibility fails if any validator fails.
That is the final rule.
________________


Merge Function
private function mergeEligibilityResults(array $validators)
{
    $allReasons = [];
    $hardFailCategory = null;
    foreach ($validators as $validatorName => $result) {
        if (!$result['passed']) {
            $allReasons = array_merge($allReasons, $result['reasons']);


            if ($hardFailCategory === null) {
                $hardFailCategory = $validatorName;
            }
        }
    }
    return [
        'eligible' => empty($allReasons),
        'eligibility_status' => empty($allReasons) ? 'pass' : 'fail',
        'eligibility_reason_codes' => array_values(array_unique($allReasons)),
        'hard_fail_category' => $hardFailCategory
    ];
}

15) FINAL CANONICAL DEFINITION
The Eligibility Engine determines whether a candidate entity remains structurally, operationally, temporally, contextually, and qualitatively valid enough to participate anywhere in the feed.
It excludes only entities that are invalid, impossible, misleading, clearly unusable, or too weak / junk.
It must not exclude entities merely because they are poorly timed, less convenient, less exciting, lower priority, or not ideal for the current moment.
________________


16) FINAL IMPORTANT BOUNDARY
Eligibility should NEVER exclude because:
   * it is closed at this hour
   * it is far away
   * it is not exciting enough
   * it is weak for current weather
   * it is better tomorrow than now
   * it is not ideal for the current slot
Those belong to later engines.
