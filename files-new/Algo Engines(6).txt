MODULE — OPPORTUNITY ENGINE — FULL IMPLEMENTATION READY SPEC
________________


0) WHAT THIS MODULE SHOULD DO
The Opportunity Engine should answer:
“Why is this item especially worth surfacing right now?”
It should temporarily boost candidates when they are unusually relevant due to:
* time of day
* weather / environmental conditions
* operational urgency
* behavioral practicality
* human need-state
It should not replace your main ranking logic.
It should only produce:
* opportunity_active
* opportunity_score
* opportunity_type_primary
* opportunity_type_secondary
* need_state_windows_active
* active_opportunity_windows
And these values should later be used inside final ranking.
________________


1) FINAL ARCHITECTURE
We will build this in 3 layers:
________________


LAYER A — STATIC ENTITY PROFILE
This stores each entity’s general “opportunity behavior”.
Table:
* entity_opportunity_profile
Examples:
* Is this good at sunset?
* Is this a quick stop?
* Is this useful for lunch?
* Is this good when hot / rainy?
* Is this a good cooling break?
* Is this better early before crowds?
This is semi-static and can be precomputed.
________________


LAYER B — LIVE SESSION / MOMENT STATE
This stores what is happening right now.
Tables:
* context_live_conditions
* session_need_state
Examples:
* Is it sunset right now?
* Is it hot?
* Is the user likely hungry?
* Is this a short commitment moment?
* Is it a drinks window?
* Is it a cooling break moment?
This is recomputed frequently.
________________


LAYER C — COMPUTED OPPORTUNITY OUTPUT
This stores the final opportunity result for candidate entities.
Table:
* entity_opportunity_state
This is the output of the engine.
________________

TABLE 1 — entity_opportunity_profile
This is the most important table.
CREATE TABLE entity_opportunity_profile (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,


  entity_type ENUM('sight','restaurant','experience') NOT NULL,
  entity_id BIGINT UNSIGNED NOT NULL,


  -- Time / daypart fit
  sunrise_relevance_score DECIMAL(6,3) DEFAULT 0,
  sunset_relevance_score DECIMAL(6,3) DEFAULT 0,
  morning_relevance_score DECIMAL(6,3) DEFAULT 0,
  afternoon_relevance_score DECIMAL(6,3) DEFAULT 0,
  evening_relevance_score DECIMAL(6,3) DEFAULT 0,
  night_relevance_score DECIMAL(6,3) DEFAULT 0,


  -- Weather / environment fit
  indoor_suitability_score DECIMAL(6,3) DEFAULT 0,
  outdoor_dependency_score DECIMAL(6,3) DEFAULT 0,
  clear_weather_bonus_score DECIMAL(6,3) DEFAULT 0,
  rainy_weather_penalty_score DECIMAL(6,3) DEFAULT 0,


  -- Practicality fit
  crowd_avoidance_value DECIMAL(6,3) DEFAULT 0,
  early_day_advantage_score DECIMAL(6,3) DEFAULT 0,
  half_day_fit_score DECIMAL(6,3) DEFAULT 0,
  quick_stop_fit_score DECIMAL(6,3) DEFAULT 0,
  short_commitment_fit_score DECIMAL(6,3) DEFAULT 0,


  -- Need-state fit (food / comfort / social)
  breakfast_fit_score DECIMAL(6,3) DEFAULT 0,
  lunch_fit_score DECIMAL(6,3) DEFAULT 0,
  coffee_fit_score DECIMAL(6,3) DEFAULT 0,
  dinner_fit_score DECIMAL(6,3) DEFAULT 0,
  late_night_fit_score DECIMAL(6,3) DEFAULT 0,


  hydration_fit_score DECIMAL(6,3) DEFAULT 0,
  cooling_break_fit_score DECIMAL(6,3) DEFAULT 0,
  shade_break_fit_score DECIMAL(6,3) DEFAULT 0,
  sit_down_rest_score DECIMAL(6,3) DEFAULT 0,


  drinks_fit_score DECIMAL(6,3) DEFAULT 0,
  stroll_fit_score DECIMAL(6,3) DEFAULT 0,
  nightlife_warmup_fit_score DECIMAL(6,3) DEFAULT 0,


  -- Visit shape
  typical_visit_duration_mins INT DEFAULT NULL,


  -- Optional metadata
  profile_confidence DECIMAL(6,3) DEFAULT 0.50,
  source_url TEXT DEFAULT NULL,


  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,


  PRIMARY KEY (id),
  UNIQUE KEY uniq_entity (entity_type, entity_id),
  KEY idx_entity_type (entity_type),
  KEY idx_entity_id (entity_id)
);

A1) TIME / DAYPART FIELDS
________________


sunrise_relevance_score
Meaning
How unusually suitable the entity is around sunrise.
Strong for:
* viewpoints
* waterfronts
* promenades
* parks
* scenic lookouts
* bridges
* river walks
Suggested formula
sunrise_relevance_score =
  scenic_bonus
+ view_bonus
+ open_air_bonus
+ waterfront_bonus


Practical SQL — Sight
UPDATE entity_opportunity_profile eop
JOIN Sight s
  ON eop.entity_type = 'sight' AND eop.entity_id = s.id
SET eop.sunrise_relevance_score =
  LEAST(1.000,
    (CASE WHEN s.category IN ('Viewpoint','Park','Waterfront','Scenic Walk','Bridge') THEN 0.60 ELSE 0 END) +
    (CASE WHEN s.tags LIKE '%sunrise%' THEN 0.25 ELSE 0 END) +
    (CASE WHEN s.tags LIKE '%view%' OR s.tags LIKE '%panoramic%' THEN 0.20 ELSE 0 END)
  );

A3) PRACTICALITY FIELDS
These are extremely important for real feed quality.
________________


crowd_avoidance_value
Meaning
How much better this item is if done before crowds.
High for:
* famous landmarks
* compact iconic sights
* queue-prone museums
* small photogenic spaces
Formula
crowd_avoidance_value =
  popularity_component
+ compactness_component
+ queue_risk_component


If you don’t have queue data, use popularity + compactness.
Simple SQL approach
UPDATE entity_opportunity_profile eop
JOIN Sight s
  ON eop.entity_type = 'sight' AND eop.entity_id = s.id
SET eop.crowd_avoidance_value =
  CASE
    WHEN s.TATotalReviews >= 5000 THEN 0.90
    WHEN s.TATotalReviews >= 2000 THEN 0.75
    WHEN s.TATotalReviews >= 500 THEN 0.55
    ELSE 0.25
  END;


This is a solid first approximation.
________________


early_day_advantage_score
Meaning
How much it is genuinely better early in the day.
High for:
* markets
* photogenic landmarks
* famous attractions
* exposed outdoor walks
SQL idea
UPDATE entity_opportunity_profile eop
JOIN Sight s
  ON eop.entity_type = 'sight' AND eop.entity_id = s.id
SET eop.early_day_advantage_score =
  LEAST(1.000,
    (CASE WHEN s.category IN ('Landmark','Viewpoint','Market','Park') THEN 0.45 ELSE 0 END) +
    (CASE WHEN eop.crowd_avoidance_value >= 0.70 THEN 0.35 ELSE 0 END)
  );


________________


half_day_fit_score
Meaning
How naturally this fits into a meaningful 2–4 hour slot.
High for:
* major museums
* large parks
* zoo
* palaces
* cruise experiences
* large complexes
Formula by duration
UPDATE entity_opportunity_profile
SET half_day_fit_score =
  CASE
    WHEN typical_visit_duration_mins >= 180 THEN 0.95
    WHEN typical_visit_duration_mins >= 120 THEN 0.75
    WHEN typical_visit_duration_mins >= 90 THEN 0.55
    ELSE 0.15
  END;

quick_stop_fit_score
Meaning
How suitable this is for a short 15–45 min moment.
High for:

* short scenic stops
* coffee stops

SQL
UPDATE entity_opportunity_profile

short_commitment_fit_score
Meaning
How easy / low-friction / low-energy this feels.
This is not only duration.
It includes:
* easy entry
* no booking friction
* mentally light
* easy stop-in behavior
High for:
* cafés
* scenic streets
* plazas
* promenades
* food markets
* quick museums
Good heuristic
short_commitment_fit_score =
  0.5 * quick_stop_fit_score
+ 0.3 * low_friction_category_bonus
+ 0.2 * no_reservation_bonus


If you don’t have reservation data, ignore that part.

PHP helper — detect windows
function detectActiveOpportunityWindows($live) {
    $now = \Carbon\Carbon::parse($live->local_datetime);
    $sunrise = \Carbon\Carbon::parse($live->sunrise_time);
    $sunset = \Carbon\Carbon::parse($live->sunset_time);


    return [
        'sunrise_window' => $now->between($sunrise->copy()->subMinutes(45), $sunrise->copy()->addMinutes(60)),
        'sunset_window' => $now->between($sunset->copy()->subMinutes(75), $sunset->copy()->addMinutes(45)),


        'breakfast_window' => $now->format('H:i:s') >= '07:30:00' && $now->format('H:i:s') <= '10:30:00',
        'lunch_window' => $now->format('H:i:s') >= '11:30:00' && $now->format('H:i:s') <= '14:30:00',
        'coffee_window' => (
            ($now->format('H:i:s') >= '09:00:00' && $now->format('H:i:s') <= '11:30:00') ||
            ($now->format('H:i:s') >= '15:00:00' && $now->format('H:i:s') <= '17:30:00')
        ),
        'dinner_window' => $now->format('H:i:s') >= '18:30:00' && $now->format('H:i:s') <= '21:30:00',
        'late_night_food_window' => (
            $now->format('H:i:s') >= '22:00:00' || $now->format('H:i:s') <= '02:00:00'
        ),
        'nightlife_window' => (
            $now->format('H:i:s') >= '20:30:00' || $now->format('H:i:s') <= '01:30:00'
        ),


        'weather_good_for_outdoors' =>
            $live->rain_probability < 0.25 &&

A) Hunger
function computeHungerLevel($now, $hoursSinceStart = 0, $walkingMinutes = 0, $recentMeal = false) {
    $time = $now->format('H:i:s');


    $base = 0.20;
    if ($time >= '08:00:00' && $time <= '10:00:00') $base = 0.85;
    elseif ($time >= '12:00:00' && $time <= '14:30:00') $base = 0.90;
    elseif ($time >= '19:00:00' && $time <= '21:30:00') $base = 0.90;


    $tripFactor = min($hoursSinceStart / 8, 0.25);
    $walkingFactor = min($walkingMinutes / 300, 0.20);
    $recentMealDecay = $recentMeal ? 0.50 : 0.0;


    return clamp01($base + $tripFactor + $walkingFactor - $recentMealDecay);
}


________________


B) Coffee
function computeCoffeeNeedLevel($now, $fatigueLevel = 0, $recentCoffee = false) {
    $time = $now->format('H:i:s');


    $base = 0.10;
    if (($time >= '09:00:00' && $time <= '11:30:00') || ($time >= '15:00:00' && $time <= '17:30:00')) {
        $base = 0.75;
    }


    $fatigueBoost = 0.25 * $fatigueLevel;
    $recentDecay = $recentCoffee ? 0.45 : 0.0;


    return clamp01($base + $fatigueBoost - $recentDecay);
}

C) Hydration / Cooling
function computeHydrationNeedLevel($temperatureC, $walkingMinutes = 0, $hoursSinceRest = 0) {
    $heatFactor = max(0, ($temperatureC - 20) / 18);
    $walkFactor = min($walkingMinutes / 240, 0.25);
    $restFactor = min($hoursSinceRest / 4, 0.20);


    return clamp01($heatFactor + $walkFactor + $restFactor);
}


function computeCoolingNeedLevel($temperatureC, $uvIndex = 0) {
    $tempFactor = max(0, ($temperatureC - 26) / 12);
    $uvFactor = $uvIndex >= 7 ? 0.25 : 0.0;


    return clamp01($tempFactor + $uvFactor);
}

D) Fatigue / Sit-down
function computeFatigueLevel($hoursSinceStart = 0, $walkingMinutes = 0, $activitiesDone = 0) {
    $tripFactor = min($hoursSinceStart / 10, 0.35);
    $walkFactor = min($walkingMinutes / 360, 0.35);
    $activityFactor = min($activitiesDone / 6, 0.20);


    return clamp01($tripFactor + $walkFactor + $activityFactor);
}


function computeSitDownNeedLevel($fatigueLevel, $coolingNeedLevel = 0) {
    return clamp01($fatigueLevel + (0.35 * $coolingNeedLevel));
}

E) Social / Stroll
function computeSocialEnergyLevel($now, $fatigueLevel = 0) {
    $time = $now->format('H:i:s');


    $base = 0.15;
    if ($time >= '17:30:00' && $time <= '22:00:00') $base = 0.65;


    return clamp01($base - (0.25 * $fatigueLevel));
}


function computeStrollReadinessLevel($pleasantStrollWindow, $now, $timePressure = 0) {
    $time = $now->format('H:i:s');


    $postDinnerBonus = ($time >= '19:00:00' && $time <= '22:30:00') ? 0.25 : 0.0;
    $pleasantBonus = $pleasantStrollWindow ? 0.50 : 0.0;
    $pressurePenalty = 0.35 * $timePressure;


    return clamp01($pleasantBonus + $postDinnerBonus - $pressurePenalty);
}

F) Commitment / Half-day readiness
function computeShortCommitmentPreference($fatigueLevel, $timePressure = 0) {
    return clamp01((0.55 * $fatigueLevel) + (0.45 * $timePressure));
}


function computeHalfDayBlockReadiness($remainingFreeMinutes = 0, $fatigueLevel = 0) {
    if ($remainingFreeMinutes < 180) return 0.0;


    $timeFit = min($remainingFreeMinutes / 300, 1.0);
    return clamp01((0.75 * $timeFit) - (0.25 * $fatigueLevel));
}

    if (!empty($activeWindows['dinner_window']) && $state['hunger_level'] >= 0.55) $windows[] = 'dinner_window';

    if ($state['hydration_need_level'] >= 0.55) $windows[] = 'hydration_window';
    if ($state['cooling_need_level'] >= 0.55) $windows[] = 'cooling_break_window';
    if ($state['sit_down_need_level'] >= 0.55) $windows[] = 'sit_down_rest_window';

    if ($state['half_day_block_readiness'] >= 0.55) $windows[] = 'half_day_block_window';

function computeConditionOpportunity($profile, $activeWindows) {
    $scores = [];


    if (!empty($activeWindows['weather_good_for_outdoors'])) {
        $scores[] = (0.6 * $profile->outdoor_dependency_score) + (0.4 * $profile->clear_weather_bonus_score);

    if (!empty($activeWindows['weather_bad_for_outdoors'])) {
        $scores[] = $profile->indoor_suitability_score;

    if (!empty($activeWindows['pleasant_stroll_window'])) {
        $scores[] = $profile->stroll_fit_score;

    return !empty($scores) ? max($scores) : 0;

C) OPERATIONAL SCORE
This one is important.
If you have operational windows, this can create strong “why now” boosts.
________________


Urgency helper
function computeOperationalUrgency($windowStart, $windowEnd, $now, $curve = 'linear') {
    $nowTs = strtotime($now);
    $startTs = strtotime($windowStart);
    $endTs = strtotime($windowEnd);


    if ($nowTs > $endTs) return 0;


    if ($nowTs < $startTs) {
        $minutesToStart = max(0, ($startTs - $nowTs) / 60);
        $preWindow = 120;


        $base = max(0, 1 - ($minutesToStart / $preWindow));
    } else {
        $minutesToEnd = max(0, ($endTs - $nowTs) / 60);
        $preClose = 90;


        $base = max(0, 1 - ($minutesToEnd / $preClose));
    }


    if ($curve === 'fast_rise') return clamp01(pow($base, 0.7));
    if ($curve === 'hard_cutoff') return clamp01(pow($base, 0.5));


    return clamp01($base);
}


________________


Main operational score
function computeOperationalOpportunity($entity, $operationalWindows, $now) {
    $best = 0;


    foreach ($operationalWindows as $window) {
        $urgency = computeOperationalUrgency(
            $window->window_start,
            $window->window_end,
            $now,
            $window->urgency_curve
        );


        $fit = 0.8; // default operational fit
        $score = $urgency * $fit * $window->importance_multiplier;


        if ($score > $best) $best = $score;
    }


    return clamp01($best);
}


If no operational windows exist, return 0.

function computeNeedStateOpportunity($profile, $sessionState) {
    $scores = [];


    $mealFit = max(
        $profile->breakfast_fit_score,
        $profile->lunch_fit_score,
        $profile->dinner_fit_score,

    $scores[] = $sessionState['stroll_readiness_level'] * $profile->stroll_fit_score;


    return !empty($scores) ? max($scores) : 0;
}

function computeFinalOpportunityScore($temporal, $condition, $operational, $practicality, $needState) {
    return clamp01(
        (0.18 * $temporal) +
        (0.16 * $condition) +
        (0.28 * $operational) +
        (0.16 * $practicality) +
        (0.22 * $needState)
    );
}

function determinePrimaryOpportunityType($temporal, $condition, $operational, $practicality, $needState) {

function determineSecondaryOpportunityTags($activeWindows, $needWindows) {

    foreach ($activeWindows as $key => $active) {
        if ($active) $tags[] = $key;

    foreach ($needWindows as $window) {

    return array_values(array_unique($tags));
}

public function run($sessionId, $contextLocationId, $candidateEntities, $routeState = [], $sessionBehavior = [], $remainingFreeMinutes = 0)
{
    $live = app(LiveContextService::class)->getLiveConditions($contextLocationId);
    $activeWindows = app(LiveContextService::class)->detectActiveOpportunityWindows($live);


    $sessionState = app(NeedStateService::class)->compute(
        $sessionId,
        $contextLocationId,
        $live,
        $routeState,
        $sessionBehavior,
        $remainingFreeMinutes,
        $activeWindows
    );


    foreach ($candidateEntities as $candidate) {
        $profile = $this->getOpportunityProfile($candidate->entity_type, $candidate->entity_id);
        if (!$profile) continue;


        $operationalWindows = $this->getOperationalWindows($candidate->entity_type, $candidate->entity_id, $live->local_datetime);


        $temporal = computeTemporalOpportunity($profile, $activeWindows);
        $condition = computeConditionOpportunity($profile, $activeWindows);
        $operational = computeOperationalOpportunity($candidate, $operationalWindows, $live->local_datetime);
        $practicality = computePracticalityOpportunity($profile, $sessionState, $activeWindows);
        $needState = computeNeedStateOpportunity($profile, $sessionState);


        $opportunityScore = computeFinalOpportunityScore($temporal, $condition, $operational, $practicality, $needState);
        $opportunityActive = $opportunityScore >= 0.35 ? 1 : 0;


        $primaryType = determinePrimaryOpportunityType($temporal, $condition, $operational, $practicality, $needState);
        $secondaryTags = determineSecondaryOpportunityTags($activeWindows, $sessionState['active_need_windows']);


        DB::table('entity_opportunity_state')->updateOrInsert(
            [
                'session_id' => $sessionId,
                'entity_type' => $candidate->entity_type,
                'entity_id' => $candidate->entity_id,
            ],
            [
                'context_location_id' => $contextLocationId,
                'opportunity_active' => $opportunityActive,
                'opportunity_score' => $opportunityScore,


                'opportunity_type_primary' => $primaryType,
                'opportunity_type_secondary' => json_encode($secondaryTags),


                'need_state_windows_active' => json_encode($sessionState['active_need_windows']),
                'active_opportunity_windows' => json_encode(array_keys(array_filter($activeWindows))),


                'temporal_opportunity_score' => $temporal,
                'condition_opportunity_score' => $condition,
                'operational_opportunity_score' => $operational,
                'practicality_opportunity_score' => $practicality,
                'need_state_opportunity_score' => $needState,


                'opportunity_confidence' => $profile->profile_confidence ?? 0.5,
                'opportunity_explanation' => $this->buildOpportunityExplanation($primaryType, $secondaryTags),


                'computed_at' => now(),
            ]
        );
    }
}
