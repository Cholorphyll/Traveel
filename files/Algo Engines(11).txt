2. TIME / DAY STATE
Fields Explained
2.1 current_time_local
* User’s local time at location
* Derived via timezone mapping
SELECT NOW() AT TIME ZONE location_timezone


________________


2.2 daypart
Represents behavioral context, not just time.
Daypart
	Time Range
	early_morning
	sunrise → +2h
	morning
	+2h → 11:30
	midday
	11:30 → 15:30
	afternoon
	15:30 → sunset-1h
	golden_hour
	sunset-1h → sunset
	evening
	sunset → +2h
	night
	after +2h
	CASE
  WHEN now BETWEEN sunrise AND sunrise + INTERVAL '2 hour' THEN 'early_morning'
  WHEN now < TIME '11:30' THEN 'morning'
  WHEN now < TIME '15:30' THEN 'midday'
  WHEN now < sunset - INTERVAL '1 hour' THEN 'afternoon'
  WHEN now <= sunset THEN 'golden_hour'
  WHEN now <= sunset + INTERVAL '2 hour' THEN 'evening'
  ELSE 'night'
END


________________


2.3 minutes_to_sunset
EXTRACT(EPOCH FROM (sunset - now)) / 60


Used heavily for:
* urgency scoring
* golden hour triggers

4. COMFORT STATE
This is where things get intelligent.
________________


4.1 Heat Stress Level
Accounts for:
* temperature
* humidity
Formula (simplified heat index logic)
heat_index =
  temperature_c + (0.33 * humidity/100 * 6.105 * e^(17.27 * temperature / (237.7 + temperature)))
  - 4


Bucketing
Value
	Level
	< 25
	low
	25–32
	moderate
	32–40
	high
	> 40
	extreme
	________________


4.2 Rain Discomfort Level
CASE
  WHEN precipitation_mm = 0 THEN 0
  WHEN precipitation_mm < 1 THEN 0.3
  WHEN precipitation_mm < 5 THEN 0.6
  ELSE 1
END


________________


4.3 Sun Exposure Level
Uses:
* UV index (if available)
* fallback: cloud cover
sun_exposure =
CASE
  WHEN uv_index >= 8 THEN 1
  WHEN uv_index >= 5 THEN 0.7
  WHEN cloud_cover > 70 THEN 0.2
  ELSE 0.5
END


________________


4.4 Wind Discomfort
CASE
  WHEN wind_speed_kmh < 10 THEN 0
  WHEN wind_speed_kmh < 25 THEN 0.4
  WHEN wind_speed_kmh < 40 THEN 0.7
  ELSE 1
END


________________


4.5 Thermal Comfort Score (CORE METRIC)
Final normalized score (0–100)
thermal_comfort_score =
  100
  - (heat_stress_level * 25)
  - (rain_discomfort_level * 20)
  - (wind_discomfort_level * 15)
  - (sun_exposure_level * 10)


Clamp between 0–100.

5. SCENIC CONDITION STATE
This is what makes your system feel magical.
________________


5.1 Visibility Quality
Uses:
* visibility (meters)
* humidity
* pollution (optional)
visibility_quality =
CASE
  WHEN visibility > 10000 THEN 1
  WHEN visibility > 5000 THEN 0.7
  WHEN visibility > 2000 THEN 0.4
  ELSE 0.1
END


________________


5.2 Sunset Quality  (VERY IMPORTANT)
Derived from:
* cloud coverage
* humidity
* pollution
Ideal conditions:
* partial clouds (20–60%)
* low humidity
sunset_quality =
  (1 - ABS(cloud_cover - 40)/40)
  * (1 - humidity/100)


Clamp between 0–1.
________________


5.3 Viewpoint Quality
viewpoint_quality =
  visibility_quality * (1 - rain_discomfort_level)
